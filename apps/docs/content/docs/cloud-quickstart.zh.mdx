<Callout type="info">
智能体执行前，运行它的电脑上需要有至少一款已安装并登录的[支持的 AI 编程工具](/providers)，例如 Claude Code、Codex 或 Cursor。CodeOPC 不自带这些工具。
</Callout>

<Steps>
<Step>

## 登录，进入工作区 [#1-登录进入工作区]

用 Web（[code-opc.benlai.com](https://code-opc.benlai.com)）或 [CodeOPC Desktop](https://code-opc.benlai.com/download) 打开应用后，点击 **企业微信登录**，在企业微信中确认授权即可自动完成登录并进入工作区。使用 Desktop 登录会自动连接当前电脑作为运行时。

</Step>
<Step>

## 连接一台电脑 [#2-连接一台电脑]

智能体在你连接的电脑上执行工作。下载并登录 [CodeOPC Desktop](https://code-opc.benlai.com/download) 后，打开侧边栏 **AI 团队** 下的 **运行时**：

- Desktop 会自动把当前电脑注册为运行时，并检测本机已安装的 AI 编程工具。
- 如果刚刚新安装了 AI 编程工具，点「刷新」重新检测即可。

**成功标志**：运行时列表里出现一台在线的电脑。

</Step>
<Step>

## 创建一个智能体 [#3-创建一个智能体]

打开侧边栏 **AI 团队** 下的 **智能体**，点 **新建智能体**。先选择刚连接的电脑上的一款 AI 编程工具，再填名称，点 **创建智能体**。必填的只有运行时和名称。

不想从头写配置，可以在配置页点 **让 AI 帮我写**，由 Agent Builder 提问并补全；这需要所选运行时在线。其余配置可以之后完善，详见[创建和配置智能体](/agents-create)。

**成功标志**：智能体列表中出现你的智能体，并显示为在线。

</Step>
<Step>

## 把第一个任务交给它 [#4-把第一个任务交给它]

点侧边栏顶部的 **新建任务**（或按快捷键 `C`）。在默认的智能体模式下：

1. 在 **创建者** 中选择刚创建的智能体；
2. 用一两句话描述要做的事，例如"介绍一下这个工作区可以怎么用"；
3. 提交。CodeOPC 会创建任务、把智能体设为负责人并立即开始执行。

![新建任务弹窗的智能体模式：Created by 已选中 CodeOPC Assistant](/images/docs/quickstart-new-issue.webp)

</Step>
<Step>

## 查看进度和结果 [#5-查看进度和结果]

提交后打开这条任务：执行日志显示运行状态，智能体的进展和回复出现在时间线中。

**成功标志**：执行日志状态变为"已完成"，时间线中出现智能体的回复。需要查看完整过程时，点"查看记录"。

![任务中智能体的回复与已完成的执行日志](/images/docs/quickstart-run-result.webp)

</Step>
</Steps>

## 常见问题

| 现象 | 先检查什么 |
|---|---|
| 没有找到运行时 | 确认 AI 编程工具已经安装并能在终端中运行，然后在 Desktop 中点「刷新」。 |
| 运行时显示离线 | 确认 CodeOPC Desktop 保持打开且处于登录状态。 |
| 任务一直排队 | 确认智能体使用的运行时在线。运行时达到并发上限时，新运行会继续排队。 |
