CodeOPC Desktop 提供 macOS 和 Windows 版本。它和 Web 版使用相同的账号与工作区数据，但会在本机自动管理运行时守护进程，并为不同工作区保留各自的标签页。

## Desktop 与 Web

| | Web | Desktop |
| --- | --- | --- |
| 打开方式 | 浏览器 | 安装桌面应用 |
| 工作区标签页 | 使用浏览器标签页 | 每个工作区保留独立的一组标签页 |
| 本地运行时 | 需配合桌面端运行 | 登录后由应用自动启动 |
| 更新 | 刷新页面 | 通过桌面应用自动更新 |

临时查看或仅浏览任务时，Web 更方便；需要让智能体在本地电脑上执行代码或命令时，请保持 Desktop 运行。

两者可以同时登录，看到的数据完全同步。

## 桌面标签页

Desktop 会为每个工作区单独保存标签页。例如，你在工作区 A 打开了三个任务，切到工作区 B 后会看到 B 自己的标签页；切回 A 时，之前的三个标签页仍然保留。

<DesktopTabsDemo />

同一资源只会在当前工作区打开一次。标签页可以重新排序、固定、关闭，也会保留各自的前进、后退和滚动位置。固定的标签页排在最左边，没有关闭按钮，要先取消固定才能关；在它里面打开别的页面时会新开一个标签页，它自己停在原页面。点击或粘贴应用内链接会直接在标签页中打开，不会跳转到浏览器。

在标签页内切换看板、列表和泳道时，也会保留各视图最新的滚动位置，包括看板的横向位置和列内滚动位置。

退出登录会清除本机保存的所有标签页，避免下一位登录者看到上一个账号留下的页面。

## 语音输入

Desktop 可以在本机把语音转成文字，填入聊天、评论、回复和新建任务的描述。语音输入**默认关闭**，网页版不提供此功能。

1. 打开**设置 → 语音输入**，开启**语音输入**。
2. 下载支持所用语言的语音模型。下载需要联网，安装后在本机转写。如果页面提示本机无法使用转写，说明当前构建没有可用的语音引擎。
3. 按提示允许麦克风访问。也可以在同一设置页选择并测试麦克风。

默认的**点按或按住**模式支持两种用法：点击麦克风开始，点击勾号插入文字；或按住麦克风说话，松开后插入。插入的文字留在编辑器中，供你检查。聊天和评论的录音栏中，点击发送按钮或在录音时按 `Enter` 会转写并发送；`Esc` 取消。

语音快捷键**默认未设置**。在**设置 → 快捷键**中绑定后，只要支持的编辑器可见，即使未聚焦也能使用。**语音输入**页还可以把触发方式改为仅点按或仅按住。

### 录音与历史记录

音频在本机转写，不会为转写而上传。发送的文字按普通聊天消息或评论提交。

录音和转写文字**默认在本机保留 30 天**。在**设置 → 语音输入 → 历史记录**中，可以播放录音、复制文字、重新转写、删除单条或全部清除。**保留历史记录**可选不保留、1 天、7 天、30 天或永久。

关闭**语音输入**会隐藏麦克风并停用语音快捷键，不会删除已有录音；仍可在同一页面管理历史记录。

## 更新 Desktop

自动更新默认开启。应用在后台检查并下载新版本，下载完成后可以立即重启安装，也可以等下次退出时安装。在 **设置 → 更新** 中可以关闭自动检查，或手动检查新版本。

手动检查或下载失败时，设置页会显示简短提示和**重试**按钮。重试期间可以继续使用当前版本。如果自动更新失败，也可以直接从 [CodeOPC 下载页](https://code-opc.benlai.com/download) 重新下载最新安装包覆盖安装。
